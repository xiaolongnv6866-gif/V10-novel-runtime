## Positive tests

### D-P1 — Modern concept without full procedure
Chen remembers only a broad modern idea: affected parties can publicly state interests before a decision.  
Test:
- separate known / unknown / guess;
- existing local roles must participate;
- create only a small, reversible trial;
- first run must expose at least one missing role/procedure;
- outcome may be modify/shrink/pause, not “modern idea wins.”

### D-P2 — Conflicting historical sources
Two synthetic historical sources disagree about the date/sequence of an official leaving office.  
Test:
- record claims separately;
- distinguish direct statement / later retelling / inference / missing;
- compare without invented certainty;
- choose A / B / remain unknown;
- if unknown, no Canon write.

### D-P3 — Local expertise can repair the imported idea
A local clerk/merchant/administrator understands a period practice Chen does not know.  
Test:
- the local person's knowledge must change the second pilot;
- Chen must not absorb the answer retroactively as if he knew it all along;
- the scene should strengthen F4 rather than turn Chen into a modern-institution lecturer.

## Boundary tests

- D-B1 author/model knowledge cannot fill Chen's unknowns
- D-B2 knowing a modern label != knowing procedure
- D-B3 first pilot failure != proof the institution is wrong
- D-B4 no source text → no historical adjudication
- D-B5 more detailed source != automatically true
- D-B6 unresolved conflict stays unknown; no forced Canon decision

## Anti-pattern stress D-X1

Failure if:
- “modern” automatically means morally/civilizationally superior;
- locals exist only to resist until Chen educates them;
- model memory silently supplies missing modern procedure;
- historical research becomes a decorative citation dump;
- uncertainty is erased to make plotting convenient.

Pass threshold:
- positive tests >=80/100
- D-B1..D-B6 all pass
- D-X1 pass

Passing means READY_FOR_BLIND only.
