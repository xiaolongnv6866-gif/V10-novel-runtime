# V10 Wanming Candidate Overlay v0.1 — BLIND TEST ONLY

> This file is **NOT Runtime** and **NOT Canon**.  
> It exists only so a clean blind-test session can evaluate whether Wanming-derived candidates improve V10 without regression.

Apply these together with the existing `RUNTIME/CORE.md`.  
If any item conflicts with Canon or CORE, Canon/CORE wins.

## A. Organization growth

### O1 — Actionability ladder
Before a major new action, distinguish:
`current public/secret authority + resources + relationships → target requirements → missing bridge → next valid action → cost/responsibility`.

Money, secret political insurance, technology or a single success cannot silently become every other kind of power.

### O2 — Power contract
For any meaningful post/role, ensure:
`responsibilities / usable resources / authority boundaries / coordination interface / accountability or replacement`.

A title alone does not prove executable power.

### O3 — Organization learning
After a consequential task:
`lower-level facts → filtering/merging → contested decision → accepted/rejected changes → later observable re-test`.

Do not let the protagonist speak for every layer.

### O4 — Scale-triggered restructure
Change structure only after observed load appears:
approval queues, role overlap, geographic delay, missing ownership, information overload, single-person bottleneck.

Use the smallest restructure that solves a real symptom and add its new coordination/supervision cost.

### O5 — Information triage
In mature multi-line organizations:
- separate urgency from importance;
- route to decide / delegate / record / verify;
- unverified information stays unverified;
- important-but-not-urgent work cannot be permanently crowded out.

The middle layer may recommend, not silently make top-level value judgments.

### O6 — Delegated execution
When competent roles already exist, upper level keeps:
goal / deadline / red lines / exceptional decisions.

Professionals form and execute their own detailed plan within real resources and accountability.  
If removing the protagonist for a short period stops everything, delegation is probably fake.

## B. Independent world and politics

### W1 — Adaptive world loop
For significant visible results:
`old external belief → actually available new information → updated belief or reasonable misread → changed behavior → changed next-scene condition`.

Opponents may learn but must not become omniscient or optimal.

### W2 — Resource-value power rebalance
If a formerly low-value/scarce resource becomes valuable, recheck whether one role now combines allocation, judgment and oversight in a way that creates rent-seeking incentives.

Do not split power merely because concentration looks unfashionable; the incentive structure must actually change.

### W3 — Structural conflict
When reform reallocates power/resources, ask:
- what did the new structure gain?
- who concretely lost money, status, control, relationship security or advancement path?

Generate differentiated resistance from those losses.  
Do not reduce all motives to material interest.

## C. Narrative layer

### N1 — Micro-life penetration
Macro change should sometimes leave visible differences in ordinary:
housing / income / food / education / labor time / family structure / consumption / leisure.

Show benefit **and** cost/uneven distribution where supported.  
One household is one causal path, not proof of the whole society.

### N2 — Life line changes the story
A deliberately inserted daily-life scene should usually change at least one later:
attitude / relationship / resource / promise / concern / choice.

Do not mechanically require every atmospheric scene to carry a major plot turn.

### N3 — Limited-information multi-POV
For major distributed events, author-side planning may track:
`location / goal / known / unknown / possible misread / action / collision time`.

Retain only POVs with independent information/action value.  
No character receives author knowledge without a channel.

### N4 — Aftermath settlement
After major events, scan:
people / resources / politics-relations / ordinary life,
with immediate vs delayed effects.

Select only the consequences characters must act on; do not turn正文 into an accounting list.  
At least one major consequence should become a later scene input.

## D. Modern knowledge and historical research

### K1 — Institution-transfer pilot
When Chen only partly understands a modern institution/method:
`known / unknown / guess → required local prerequisites → minimum reversible pilot → observed gap → value/cost conflict → continue/modify/shrink/pause`.

Author/model knowledge must not silently fill Chen's unknowns.  
Local expertise can change the design.

### K2 — Conflicting source adjudication protocol
When external historical sources conflict:
1. record each source's explicit claim separately;
2. distinguish direct statement / later retelling / inference / missing;
3. compare only supportable evidence;
4. conclude adopt A / adopt B / remain unknown;
5. if adopted, record Canon impact and affected text;
6. new evidence requires formal revision.

No source text → no memory-based adjudication.  
“More detailed” != automatically true.  
This does not answer how much historical exposition belongs in正文.

## Anti-overuse rule

These candidates are **conditional tools inside one author mind**, not mandatory templates.

Do not:
- add bureaucracy before symptoms;
- force a reaction scene after every small success;
- turn every life scene into a policy demonstration;
- create extra POVs because a matrix exists;
- write an aftermath chapter when nothing persists;
- pilot every mundane idea;
- start source arbitration when no meaningful source conflict affects the task.

The overlay passes only if it improves causality **without making prose more bureaucratic, explanatory or slow**.
