# 《晚明》GLOSSARY

> Cangjie Stage 3 共享术语词典。  
> 这些词条用于理解《晚明》内部的叙事/组织语境，不等于现实历史制度定义，也不自动构成独立能力。

| 术语 | 《晚明》中的特定含义 | 来源定位 | 关联能力 |
|---|---|---|---|
| 融入 | 不是价值认同，而是先获得位置、信用、关系与力量，使人物具备改造现实的行动资格。 | 《可有可无的序》；第一卷至第二卷前段 | `actionability-ladder` |
| 政治 | 偏向现实权力关系、利益、站位与可执行性：谁能决定、谁会阻止、谁承担后果。 | 《可有可无的序》及后续军政线 | `structural-conflict`, `success-constraints`, `relationship-multiaxis` |
| 组织结构 | 把人按职责、上下级、地点与任务组织成可运行单元；文本中会随规模多次重构。 | 第二卷第13章《组织结构》；第五卷第3、36—37、153章 | `scale-restructure`, `power-contract` |
| 总结会 | 行动后从基层收集问题、由中层筛选、会议讨论，再把采纳结果写入规则/训练/岗位的反馈机制。 | 第二卷第38章《总结会》 | `learning-loop` |
| 各司 | 中后期专业部门的统称；关键不是名称，而是职责、资源、人事、协调和问责边界。 | 第五卷第36—37章 | `power-contract`, `delegated-execution` |
| 军报 / 文书流 | 规模化组织中的信息入口；承担分类、紧急/重要判断、处理建议和多线状态汇总。 | 第五卷第16章《文登军报》 | `information-triage` |
| 训导官 | 与直接指挥岗位分开的组织角色，用于沟通、教育、情绪和认同管理；其叙事价值是把“士气”落实到具体岗位。 | 第三卷第6章《训导官》 | `power-contract`, `micro-life-dashboard` |
| 屯堡体系 | 把基层人口、土地、教育、治安、生产和行政执行连接起来的社会单元；后期也暴露层级迟缓与寻租问题。 | 第五卷第153章《民事官》等 | `decentralized-pilot`, `resource-power-rebalance`, `micro-life-dashboard` |
| 总甲 / 屯长 | 基层行政骨架中的岗位；其工资、考绩、资源分配与晋升使“基层治理”成为可写的权力结构。 | 第五卷第153章《民事官》 | `power-contract`, `resource-power-rebalance` |
| 预备兵 | 文本中连接人口、财政负担、家庭与组织动员的人力层；此词在本项目只作叙事系统术语，不提供现实训练/作战说明。 | 第三卷第2章《逃——兵》等 | `success-constraints`, `aftermath-settlement` |
| 退养金 | 把个人长期保障与组织信用连接起来的福利/激励安排；其叙事作用在于让组织承诺进入个人生活。 | 第四卷第68章《军工厂与福利》 | `micro-life-dashboard`, `aftermath-settlement` |
| 四海商社 | 对外商业网络，与内部民政生产分开核算；后续兼具交易、物流、关系与信息节点功能。 | 第四卷第20章《扬——州》等 | `adaptive-opponents`, `success-constraints` |
| 四海钱庄 | 不只承担存取银钱，还被文本用于信用、结算与政治经济绑定；其扩张会随声望和力量变化。 | 第五卷第19章《田——皮》、第145章《真正的利益》 | `success-constraints`, `structural-conflict` |
| 民事官 | 地域扩大后，为解决中央各司直接管理基层过慢而提出的地方综合行政层级，并明确先做试点。 | 第五卷第153章《民事官》 | `decentralized-pilot`, `scale-restructure` |
| 舞台 | 终局阶段对领导作用的一种人物自述：通过制度、资源与空间让其他人的能力发挥，而非把成果全部归于单一英雄。 | 第六卷第82章《英——雄（上）》 | `delegated-execution`, `public-memory-recoding` |

## 使用边界

- 词条定义来自《晚明》文本内部用法，不应直接替代真实明末制度史定义。
- 人物自述（例如“政治”“舞台”）只说明角色/文本怎样组织概念，不自动等于作者普遍真理。
- 涉及军队、武器、战斗的词条只保留叙事系统层意义，不转化为现实危险活动的操作方法。
