# V10 Blind Test Protocol v0.1

## 目的
测试一个没有本项目旧聊天上下文的全新 ChatGPT 会话，能否仅凭本仓库恢复 V10 的核心创作能力与项目状态。

## 被测会话规则
1. 只允许以本仓库为项目依据。
2. 必须先读取 `V10_SKILL.md` 并严格执行其恢复流程。
3. 完成恢复后，读取并回答 `TESTS/BLIND_TESTS.md` 全部 40 题。
4. 不要求用户补充背景，不依赖“以前聊过”的记忆。
5. 回答时按 1–40 编号，答案应简洁但能体现判断依据。
6. 不读取或索取任何答案钥匙、评分标准或本旧聊天记录。
7. 如果仓库内容不足以支持某个判断，必须明确指出“仓库依据不足”，不得凭空补写。
8. 完成后给出一段不超过 200 字的自检：哪些题最不确定、是否发现仓库内部冲突。

## 通过标准
由旧会话中的评估者评分。总分 40 分，目标至少 38/40（95%）。

注意：被测会话不要自己宣布“通过/失败”，只提交答案。
